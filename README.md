## 💻 Sobre o projeto

O Scale Fintech é um projeto de site institucional desenvolvido para uma empresa do setor financeiro. A proposta é apresentar uma interface moderna e profissional, destacando segurança, confiança, praticidade e tecnologia na gestão financeira.

O projeto possui uma navegação simples e organizada, com foco em proporcionar uma experiência agradável ao usuário e apresentar os principais serviços e diferenciais da empresa.

## 🚀 Como executar o projeto

1. Baixe ou clone o projeto.
2. Abra a pasta do projeto no seu editor de código.
3. Execute o arquivo `index.html` no navegador.

### Pré-requisitos

Antes de começar, você vai precisar ter instalado em sua máquina:

- Um bom editor de código, como o [VS Code](https://code.visualstudio.com/)
